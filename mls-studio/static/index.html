Settings

AutoHDR API app

Create an API app at new.autohdr.com/api and paste its client ID and secret. The app talks to the same AutoHDR API that the AutoHDR MCP server uses, under the studio account's credits.

Frame.io (Adobe Developer Console)

In developer.adobe.com/console create a project, add the Frame.io API, then pick a credential:

The sign-in lands on a local HTTPS page with a self-signed certificate; Safari or Chrome will warn once. Choose “visit anyway” — it is this app on your own Mac.

Slack

Posts a delivery note to #general after every Frame.io upload. In api.slack.com/apps: Create New App → From scratch → name it Studio Hub → Incoming Webhooks → activate → Add New Webhook to Workspace → pick #general → copy the URL.

Studio Hub

Shows this Mac's jobs on the Studio Hub home page (the MLS Studio · in progress card) so the whole team can see what is running. Daniel shares the hub key with the other setup values.
