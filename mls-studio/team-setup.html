MLS Studio turns a shoot folder into a finished delivery: AutoHDR edits the photos, a High Res set and an MLS set under 4 MB land in the client's Frame.io folder, the client gets a share link, and #general hears about it. It lives in the Studio Hub under Post-Production. This document walks through the one-time setup on your Mac, a practice run, and what day-to-day use looks like. Setup · Steps 1–3

Install and connect

Do these in order on the Mac you edit from. Each one ends with a green check inside the app, so you know it worked before moving on.

1
Install and start it 1 min

Press ⌘-Space, type Terminal, press Return. Paste this line and press Return. It installs MLS Studio into ~/Applications/MLS Studio, starts it, and opens the page in your browser.

curl -fsSL https://anomalycreativeco.github.io/mls-studio/install.sh | zsh
If macOS asks whether Terminal may access your Desktop or Downloads folder, click Allow. That permission is what lets it read shoot folders.

Leave the Terminal window open while you use MLS Studio. Ctrl-C in that window stops it. Run the same line again any time to update.

2
AutoHDR 1 min
  1. On the page click Settings (top right) → AutoHDR API app.
  2. Paste the AutoHDR client ID and client secret from the last page.
  3. Press Test AutoHDR. Green: the studio email and the credit balance.
3
Frame.io 3 min
  1. Settings → Frame.io. Leave OAuth Web App selected.
  2. Paste the Adobe client ID and client secret from the last page. Press Connect Frame.io.
  3. Adobe asks you to sign in: use the Adobe ID tied to your Frame.io seat, then approve.
  4. A page warns the connection is not private. That is MLS Studio on your own Mac. Safari: Show Details → visit this website. Chrome: Advanced → Proceed to localhost. This happens once.
  5. Back in MLS Studio press Test Frame.io: your name and “1 account”.
Test says 0 accounts? You signed in with a different Adobe ID. Press Disconnect, Connect again, and pick the one on your Frame.io seat.

Setup · Steps 4–5

Slack, then a practice run

4
Slack, then Save 1 min
  1. Settings → Slack. Paste the webhook URL from the last page. Press Send a test message; a line appears in #general.
  2. Press Save.
5
A three-photo practice run 3 min · 3 credits
  1. Make a folder on the Desktop with three finished JPEGs in it.
  2. Choose folder… and pick it. Shoot name: your first name plus “test”.
  3. Step 2 on the page: switch to Finished photos — skip HDR.
  4. Step 3: in the Frame.io browser click Studio Hub Tests. The folder you are standing in is the output folder.
  5. Press Run. About a minute later the job card says Done, with links to the local folders, the Frame.io folder and the client share link, and #general gets the note.
Day to day · running a real shoot

Start it, then open it from the hub. Run the install line again (or python3 ~/Applications/MLS\ Studio/server.py --open), then Studio Hub → Post-Production → MLS Studio, or go straight to localhost:8765.

Brackets or camera files: leave the full HDR pipeline on, pick the interior and exterior looks, tick the enhancements the listing needs. RAW sets of 40–50 photos take AutoHDR about 30 minutes; the page keeps polling.

Frame.io: paste the client's next.frame.io project or folder link into the box, or click through the browser. A folder named after the shoot is created there with High Res and MLS inside, plus a client share link.

Closed the Terminal mid-job? Start it again; the job shows interrupted and Resume picks up where it stopped.

Reference

Credits, and if something doesn't match

What a delivery costs
  • Everything bills the studio AutoHDR account, no matter who runs it. Upload and processing are free on house looks.
  • House looks (Classic, Lisa, the V4 skies, the twilights) cost 1 credit per finished photo when the High Res set is downloaded. Re-downloads are free.
  • Creator looks (Aura, Fuse, Brut, Kasl, Editorial) show their per-photo price in the dropdown and bill when processing finishes, download or not.
  • A re-edit prompt is 1 credit per photo. The run bar shows the estimate and the live balance before you press Run.
  • Brackets merge into one photo, so a 150-file bracketed shoot is about 50 photos, not 150.
If something doesn't match
The hub card says “MLS Studio isn't running on this Mac”
It only runs while the Terminal window is open. Run the install line again. Chrome may ask once to allow the site to reach your local network; allow it.
A “Restart needed” banner at the top of the page
The page is newer than the server behind it. Ctrl-C in Terminal, run the start line again, reload.
The folder shows fewer photos than it holds
Videos and other non-photo files are left out on purpose; the scan line lists them. Subfolders are ignored, so run each shoot folder on its own.
The certificate warning has no “proceed” option
Safari hides it under Show Details; Chrome under Advanced. If a managed browser blocks it, open the address in Safari.
Adobe says “invalid redirect_uri” when connecting
Nothing on your side; the studio's Adobe credential needs the redirect address https://localhost:8766/callback. Tell Daniel.
The AutoHDR test fails
Usually a stray space at the end of a pasted value. A failed test stores nothing, so paste again and retry.
