MLS Studio isn't running on this Mac

MLS Studio runs locally because it reads the shoot folder straight off your drive, then sends it to AutoHDR, resizes the MLS set and delivers to Frame.io. Start it and this page turns into the app.

Already installed? Start it.Paste in Terminal (⌘-Space, type Terminal). Leave the window open while you work.
python3 ~/Applications/MLS\ Studio/server.py --open
First time on this Mac? Install it.One line; it downloads MLS Studio into ~/Applications/MLS Studio and starts it. Run the same line again any time to update.
curl -fsSL https://anomalycreativeco.github.io/mls-studio/install.sh | zsh
Then come back here.This page checks every few seconds and switches to the app as soon as it answers. Or open it directly at localhost:8765.
Setup for a new Mac (AutoHDR app, Adobe sign-in for Frame.io, Slack) is inside the app under Settings; the studio's step-by-step page is Connecting Frame.io & AutoHDR.
